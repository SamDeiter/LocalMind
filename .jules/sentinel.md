## 2025-07-05 - Reversed Arguments in safe_resolve
**Vulnerability:** Path jailing in `PromptGuard` was completely ineffective because `safe_resolve` was called with its arguments reversed (`safe_resolve(user_path, base_dir)` instead of `safe_resolve(base_dir, user_path)`).
**Learning:** Even with a robust security utility like `safe_resolve`, a simple call-site error can negate all protections. Furthermore, the fallback implementation for `safe_resolve` (used when imports fail) was also incorrect, failing to prepend the base directory.
**Prevention:** Standardize security utility signatures and use strict type checking or automated security tests that specifically target the jail boundary. Always verify security utilities with negative test cases (traversal attempts) in the actual call sites, not just in isolation.
