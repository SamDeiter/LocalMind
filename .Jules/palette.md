## 2025-05-15 - Enhancing Typing Indicator Accessibility
**Learning:** The AI typing indicator in the chat interface was missing standard ARIA roles and labels, making it invisible to screen reader users during the "thinking" phase. Adding `role="status"` and `aria-label="AI is thinking"` provides immediate feedback for assistive technologies. Additionally, when using `element.style.display = ""` in JavaScript to reveal elements (like the restored `#stopBtn`), it is important to use inline `style="display: none"` in the HTML rather than Tailwind's `hidden` class to ensure the visibility is correctly restored.
**Action:** Always include `role="status"` and a descriptive `aria-label` for live regions like typing indicators, and prioritize inline styles for elements whose visibility is managed by `chat.js`.
